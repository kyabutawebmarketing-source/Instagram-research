# hakutakagami 接触冷感ドッグウェア 特集LP

現代美術作家・加賀美健とのコラボブランド「hakutakagami」の接触冷感ドッグウェア3商品
（涼ティー／なんかちょっといい気分／なんかちょっとかいてき）を特集する、
Shopify Online Store 2.0 対応のランディングページ一式です。

- メインコンセプト：**「アートを着て、夏を涼しく。」**
- 実装方式：**カスタムセクション + 専用ページテンプレート（JSON）**
- 既存テーマの共通ファイルは一切変更しません（すべてLP専用ファイルとして分離）

> **前提**
> このリポジトリにはShopifyテーマ本体が含まれていなかったため、Dawn系の
> Online Store 2.0テーマにそのままアップロードできる構成で制作しています。
> コンテンツ幅はテーマ設定 `page_width`、フォントはテーマのCSS変数
> `--font-body-family` / `--font-heading-family` があれば自動的に踏襲し、
> ない場合は安全なフォールバック値（1200px / inherit）で表示されます。
> ヘッダー・フッターは既存テーマのものがそのまま表示されます。

## 2. Shopify管理画面でのLP作成手順

### 2-1. ファイルのアップロード

1. Shopify管理画面 →「オンラインストア」→「テーマ」→ 対象テーマの「…」→「コードを編集」
2. 各ディレクトリに、本パッケージの同名ディレクトリのファイルを新規作成してコピーする
   - `sections/` → 13ファイル
   - `snippets/` → 2ファイル
   - `assets/` → 2ファイル
   - `templates/` → `page.hakutakagami-lp.json`
3. すべて **新規ファイルの追加のみ** です。既存ファイルは編集しません。

※ Shopify CLI / GitHub連携を使っている場合は、テーマリポジトリの対応ディレクトリに
ファイルを配置してデプロイしてください。

### 2-2. ページの作成とテンプレートの割り当て

1. 管理画面 →「オンラインストア」→「ページ」→「ページを追加」
2. タイトル例：`加賀美健コラボ 接触冷感ドッグウェア特集`
3. 右側の「テーマテンプレート」で **`page.hakutakagami-lp`** を選択
4. 「ウェブサイトのSEOを編集」で以下を設定（推奨案）
   - **title**：`加賀美健コラボ 接触冷感ドッグウェア特集｜hakutaka`
   - **meta description**：`現代美術作家・加賀美健とのコラボから、接触冷感素材のドッグウェアが新登場。涼ティー、なんかちょっといい気分、なんかちょっとかいてきの全3デザインをご紹介します。`
   - canonicalタグ・OGPは既存テーマの出力をそのまま使用します（LP側では出力しません）
5. 保存（公開前は「非表示」で保存し、プレビューで確認）

### 2-3. 商品の設定（重要）

テンプレートには手入力のフォールバック値（商品名・価格2,480円・画像URL）が
入っていますが、**価格・売り切れの自動反映のため、必ず商品ピッカーで商品を
選択してください。**

1. テーマエディター（「カスタマイズ」）で該当ページを開く
2. 「LP：商品ラインナップ」→ 各「商品カード」ブロック →「商品」で対象商品を選択
   - 涼ティー → `/products/pets04`
   - なんかちょっといい気分 → `/products/pets05`
   - なんかちょっとかいてき → `/products/pets06` **（要確認・下記TODO参照）**
3. 「LP：最終CTA」の3ブロックにも同様に商品を設定
4. 商品を選択すると、商品名・URL・価格（`price_min`）・売り切れ表示が自動反映されます
   （売り切れ時はバッジ表示＋CTAが「売り切れ」表記に変わります）

### 2-4. 画像の設定

テーマエディターの各セクションに画像枠があります。画像を設定しない間は、
商品カード等は指定いただいたShopify CDNの商品画像URL、その他は
プレースホルダー表示で動作します。

「コンテンツ」→「ファイル」に画像をアップロード後、各セクションの
image_picker から選択してください。

### 2-5. その他テーマエディターで変更できる項目

- 各セクションの表示・非表示（セクションの目のアイコン）・並び替え
- 見出し／本文／CTA文言／CTAリンク
- 背景色／テキスト色／アクセントカラー／上下余白（全セクション共通）
- 送料無料条件・まとめ買い価格（ヒーローの「オファー」＋まとめ買いセクション本文）
- サイズ表（テキストエリア。1行＝1サイズ、`サイズ|首回り|胴回り|着丈` 形式）
- FAQ（ブロックの追加・削除・並び替え、返品・交換規定ページへのリンク設定）
- 固定CTAの文言・リンク・表示開始スクロール量

### 2-6. 公開前の確認方法

1. テーマエディターのプレビュー、またはページを「非表示」のままプレビューURLで確認
2. 本README末尾のチェックリストを確認
3. 問題なければページを「表示」に変更して公開

### 2-7. 元に戻す方法

すべて追加ファイルのみのため、以下で完全に元へ戻せます。

1. ページのテンプレートを `page`（デフォルト）に戻す、またはページを削除
2. 追加した18ファイルをコード編集画面から削除
   （`hakutakagami-` / `page.hakutakagami-lp` で始まるファイルのみ）

既存テーマのファイルには変更を加えていないため、他ページへの影響はありません。

## 4. 実装メモ

### 計測（GTM向けdata属性）

すべての主要CTAに以下のdata属性を付与しています。GTMのクリックトリガーで
`data-lp-event` / `data-cta-position` / `data-product-handle` を参照してください。
GA4イベントを直接送信するコードは実装していません（既存計測との重複回避）。

| CTA | data-lp-event | data-cta-position | data-product-handle |
| --- | --- | --- | --- |
| ファーストビューCTA | `click_cta` | `hero` | — |
| 各商品CTA | `click_product` | `product-card` | 例 `pets04` |
| 送料無料訴求CTA | `click_cta` | `bundle` | — |
| 最終CTAの商品CTA | `click_product` | `final-cta` | 例 `pets04` |
| 固定CTA | `click_cta` | `sticky` | — |

### SEO・構造化データ

- h1はファーストビューの「アートを着て、夏を涼しく。」の1つのみ。以降はh2/h3
- FAQセクションが FAQPage 構造化データ（JSON-LD）を出力
- **Product / ItemList 構造化データは実装していません**：商品ページ側で既存テーマが
  Product構造化データを出力している可能性が高く、重複リスクがあるためです。
  必要な場合は既存テーマの出力を確認のうえ追加してください
- 架空のレビュー・評価は構造化データに含めていません
- canonical・OGPは既存テーマのlayoutの出力に委ねています

### 表現・データの取り扱い

- Q-max値・体感温度・熱中症予防効果などの未確認数値は記載していません
- FAQで「熱中症を防ぐものではありません」と明記しています
- サイズ表の数値は未確認のため「—」を初期値とし、エディターから入力する設計です
- 「創業90年以上」は本文（richtext）にあるため、確認できない場合はエディターから削除できます
- 加賀美健のプロフィール欄は空欄が初期値です（確認できる情報のみ入力する運用）

### 技術面

- CSSは `.hklp-` 名前空間で完結し、他ページへ影響しません（LPページでのみ読み込み）
- JSは固定CTA制御のみ（バニラJS・jQuery不使用・二重読み込みガード付き）
- スムーズスクロールはCSS `scroll-behavior`（`prefers-reduced-motion` で無効化）
- FAQは `<details>/<summary>` によるネイティブ実装（JS無効でも動作）
- スマホの商品ラインナップはCSSスクロールスナップの横スワイプ（JS不使用）
- 固定CTAは `env(safe-area-inset-bottom)` でiPhoneセーフエリア対応、
  表示中は `body` に余白を追加してコンテンツが隠れないようにしています
- ファーストビュー画像は `loading="eager"` + `fetchpriority="high"`、以降は `loading="lazy"`
